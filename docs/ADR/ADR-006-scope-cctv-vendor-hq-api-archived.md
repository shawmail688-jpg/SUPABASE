# ADR-006：范围定案——监控走厂商开放平台（后续项目）、总部 API 归档不排期

Status：Accepted
Date：2026-09-03
决策者：用户（v1.3 附录 A 第三轮 #2/#10/#11 + 09-03 缩围定案）
来源：Proposal v1.3 §1/§4.2/§10/§11

# 一、背景（Context）

- 领导 v1.3 提出新诉求：实时监控影像嵌入页面（位置✓基础信息✓已实现，监控是增量）
- 同时用户明确当前承诺缩围：**阶段一+阶段二**（照片上云+四态审批看板+工作视图），M5 监控与总部数据读取=后续项目不排期
- 监控链路自建（RTSP 中继）成本高、维护重；总部经营数据接入依赖国内开发答复（信函七问）

# 二、决策（Decision）

1. **监控（M5）=后续项目，方案备好不排期**：
   - 轨道：厂商开放平台（海康/大华系）——摄像头→厂商云→Edge Function 保管 appKey/secret 取一次性播放地址→页面内嵌厂商 H5 播放器；**不自建视频链路**
   - C 档自建中继=归档备胎默认不启动（触发=无云能力且必须看）
   - 前置=本地 IT 盘点四问（品牌/云平台绑定/渠道商/上行带宽）；device 表随 M5 延后不建
2. **总部 API 接入=归档轨道**：信函七问挂起不删；恢复触发=①经营数据上平台 ②在营状态自动点亮 ③总部统一数据系统落地；恢复时走 Edge Function 代理层（凭证服务端+白名单+留痕），落库数据过 external_ids 映射

# 三、候选方案与取舍（Alternatives）

| 方案 | 理由 | 否决原因 |
|------|------|----------|
| **厂商开放平台+归档备胎** ✅ | 视频基础设施全归厂商，平台零视频流量成本 | — |
| 自建 RTSP→网页中继 | 不依赖厂商云 | 服务器+带宽 $30-70/月且维护重；仅单店触发时才考虑 |
| 总部 API 现在就谈 | 一步到位 | 依赖国内开发答复，阻塞主线；归档轨道预置随时可启 |
| 监控现在立项 | 领导提过 | 用户拍板缩围：盘点答复前无法分档（A/B/C），排期是虚的 |

# 四、验证证据（如经评估 / 原型）

- 分档价目（¥3-10/路/月、加装 ¥200-500/台）为量级估计（Assumption），M5 立项时按渠道商价目表核实
- 开放平台国际区可用性为未知项，实测前置（两道闸门 §4.2）

# 五、后果（Consequences）

- 正面：当前 9-11 天工期无外部依赖；方案与安全接口预置（external_ids/entity_type='device'、Edge Function 纪律），后续立项时实现面已备好
- 代价 / 技术债：领导「监控嵌入」诉求延后满足——需在 M3a 验收时向领导明确当前不含监控
- 回退触发条件：IT 盘点答复回来 → 单独立项按 §4.2 分档评估（不回填本 Assessment，另评）
