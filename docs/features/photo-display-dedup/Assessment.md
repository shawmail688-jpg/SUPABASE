硬触发检查：未命中新技术、破坏性迁移、架构/API、安全、多服务或不可逆操作。Tiny 三查结论：项目已有 SHA-1 精确去重；本次复用现有 `photo` 元数据并补充已人工核验的历史近重复排除清单，无需新工具、依赖或权威文档研究。视觉候选阈值采用 64-bit dHash 汉明距离 ≤5（Empirical：45 张存量图扫描只命中 5 组，逐组目视确认均为同画面不同压缩版本）。
