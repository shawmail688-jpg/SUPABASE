# 三、澄清记录（历史关键 Q→A，回溯用）

- Q：site 与调查是什么关系？ → A：site≠survey，**一个 site 可挂多次 survey_result**，历次全保留永不覆盖（v1.2 附录 A 第二轮 #1）
- Q：「删除」功能怎么做？ → A：**隐藏=软删除=否决**，三态均可藏、仅 admin 可恢复，数据一条不删（v1.3 第三轮 #5）
- Q：领导权限和用户一样吗？ → A：**同权**（同属管理层）；调查员仅交表，永远碰不到候选状态（第三轮 #6）
- Q：Sheets 还做工作台吗？ → A：**取消**（09-03 批准后修订），审批/编辑/导出全走网页；Sheets=历史存档，§9 三规则降级备轨
- Q：监控现在做吗？ → A：**后续项目不排期**（09-03 缩围定案），方案备好 §4.2，device 表随 M5 延后
- Q：状态谁批？ → A：调查中是系统判的（提交即调查中）；候选/已选是管理层批出来的（§8.4 判定规则）
- Q：存量照片迁不迁入 Storage？ → A：**迁入**（用户 09-03 L1 闸门定案），M2a 含迁移脚本
- Q：前端观感要求？ → A：**「前端可以设置的更好看一些」**（用户 09-03）→ N5 UI 视觉质量入册
