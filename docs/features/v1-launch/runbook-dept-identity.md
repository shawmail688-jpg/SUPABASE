## 0. 开工前准备

- 支付宝（阿里云买域名）；或双币卡（改走 Cloudflare 直购，见 §1 备选）
- 你的个人邮箱（收转发件用）
- **备份人选定**：备份管理员的邮箱（领导或可信同事）——他要当 Supabase 组织第二管理员 + 转转发件，先打招呼

## 1. 买域名（≈10 分钟 + 实名等待）

1. **选名**：`<公司缩写>uganda.com`（.com 优先，备选 .net/.dev）；只用于内部工具+看板，好记即可。注册商一般送 WHOIS 隐私保护，勾上
2. **阿里云万网**购买：搜索域名 → 加清单 → 支付宝付款（.com 首年 ≈¥55-79，年报口径与费用明细 QSP-2026-001 域名项一致）
3. **发票（09-09 用户定：垫资报销）**：阿里云「费用与成本 → 发票管理」申开。**09-09 财务确认：个人抬头即可报销**（与个人实名一致，开票零障碍）；公司抬头发票对企业税务略有利（进项抵扣/税前扣除）但金额太小无谓纠结，按财务口径走
4. **实名认证**：个人实名即可（身份证，几分钟到几小时过审）。**不需要 ICP 备案**——域名 NS 指向 Cloudflare、站点部署在 Cloudflare Pages，不解析到国内服务器
5. 备选：有双币卡可在 Cloudflare Registrar 直购（成本价 ≈$10，免 §2.3 改 NS 一步）；本 runbook 按阿里云走

## 2. Cloudflare 免费账号 + 接入域名（≈15 分钟 + 生效等待）

1. 注册 dash.cloudflare.com（**免费计划**；账号邮箱用你的个人邮箱即可，这是第四组要封存的凭据）
2. Add a site → 输入刚买的域名 → 选 **Free** → CF 分配两个 NS（形如 `xxx.ns.cloudflare.com`），先记下
3. 回阿里云控制台 → 域名 → 管理 → **DNS 修改** → 替换为 CF 的两个 NS → 保存
4. 回 CF 点「检查名称服务器」，等激活（几分钟到几小时，最长 24h，通常很快）

## 3. 开邮件转发 dept@（≈10 分钟）

1. CF 控制台选中域名 → **Email → Email Routing** → 开始配置
2. 添加目标地址（Destination）：你的个人邮箱 + 备份人邮箱 → **各自去邮箱点验证链接**
3. 创建自定义地址：`dept@<域名>` → 转发到上面两个目标
4. （建议）**Catch-all 开启**：所有 `*@<域名>` → 你的个人邮箱。以后给任何服务随手造别名，不用再配
5. **验证闭环**：从任一外部邮箱发信到 `dept@<域名>`，你和备份人都能收到 → 本步 DONE
   - 注意：这是「只收不发」，Supabase 注册只需收验证信，够用；将来要用 dept@ 对外发件（如给 IT 发信函）再加免费 SMTP（Resend/Zoho），不属于本步

## 4. Supabase 开户 + 组织 + 项目（≈10 分钟）

> **09-09 用户决定：可先用个人邮箱开户，不等域名。** 换绑随时可做：Account 设置里改邮箱，新旧两个邮箱各点一次确认，组织/项目/数据不受影响。前提纪律不变：独立密码（**别用 GitHub/Google OAuth**）、立即开 2FA。域名+转发就绪后尽快换绑 `dept@<域名>`，补上账号层单点。
> **误用 GitHub OAuth 注册的处置（09-09 实际发生）**：该号上不建组织/项目，直接弃用；域名转发开通后用 `dept@<域名>` 邮箱+密码重新 Sign up（验证信走转发收件箱）。以后登录认准邮箱入口，别手滑点「Sign in with GitHub」进旧号。改邮箱方案（OAuth 号改 dept@）不推荐——GitHub 登录链路仍在，账号独立性打折。
1. supabase.com → Sign up（邮箱+密码；今天可先用个人邮箱，见上）
2. 验证信进转发收件箱 → 点验证
3. **立即开 2FA**：Account → Security → 两步验证（TOTP）→ **恢复密钥抄进凭据封存清单**
4. 建 Organization：名如 `<公司缩写>-uganda`（Free 计划）
5. **邀请备份管理员**：Organization → Team → 邀请其邮箱，角色 Owner/Administrator → 对方邮件接受
6. 建 Project：名 `survey-platform`，Region 选 **Frankfurt**（TASK-001 拍板，09-04 定案）
7. 免费档提示：项目闲置一周会自动暂停——开发期天天碰不会中招，次月升 Pro 后此限制消失

## 5. 凭据封存（≈10 分钟，防单点的关键一步）

| # | 凭据组 | 含 2FA？ | 封存两处 |
|---|--------|----------|----------|
| 1 | 域名注册商（阿里云） | — | 你 + 备份人 |
| 2 | Cloudflare 账号 | 建议开 | 你 + 备份人 |
