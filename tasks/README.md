# 任务单目录（TASK-xxx）

**格式**：每任务一个文件 `TASK-xxx-<slug>.md`，字段固定：

```markdown
# TASK-xxx：<标题>
状态：TODO | DOING | REVIEW | DONE
目标：<一句话>
输入：<涉及的文档节/表/文件>
验收条件：（逐条可自动化，C6）
审查结论：（附尾部，谁审的/结论/日期）
```

**纪律**：验收条件先行再动工；DONE 必须带机器证据（测试输出/自检脚本）或用户验收记录；审查结论随任务单留痕，不另开目录。
